# 全国スポットデータの作り方（v2.5）

## 流れ

1. **抽出（GitHub Actions）**
   `osm-extract-run` ブランチに push すると、ワークフロー `.github/workflows/osm-extract.yml` が動きます。
   Geofabrik から日本全体の OpenStreetMap データ（約2GB）をダウンロードし、神社・寺院・滝・山・湧水・温泉・巨木・岩・洞窟・展望地・湖などの候補と、都道府県・市区町村の境界を取り出します。
   結果は `data-raw` ブランチ（公開しないブランチ）に `candidates.jsonl.gz` として保存します。元の2GBのデータはリポジトリに入れません。
2. **Wikidata の取得（GitHub Actions）**
   `wikidata-extract-run` ブランチに push すると、`.github/workflows/wikidata-extract.yml` が Wikidata（CC0）から日本の神社・寺院 約3.7万件の日本語名・座標・Wikipedia の言語版の数・種類（式内社・官幣社など）・祭神／本尊・文化財の指定を取得し、`data-raw` ブランチに `wikidata.jsonl.gz` として追加します。
3. **選定（手元で実行）**
   `python3 scripts/build_spots.py candidates.jsonl.gz --wikidata wikidata.jsonl.gz --target 10000 --total 100000 --extra-parts 8`
   で、最初に読み込む中心データ1万件（`data/spots-osm.js`）と、表示後に読み込む追加データ（`data/extra/spots-extra-1〜8.js`）、`data/manifest.json`・`docs/DATA_REPORT.md` を作ります。合計は10万件以内です。
4. **検査**
   `node tests/run-data-tests.js` で件数・重複・座標・都道府県・代表的なスポットの有無などを確かめます。

## Wikidata の使い方

- OSM の候補に Wikidata ID があれば、その情報を重ねます。ID がなくても、同じ種類・同じ名前（または名前の一部が一致）で1km以内なら同じものとして重ねます。
- OSM にない神社・寺院は、Wikidata の座標で新しく加えます。都道府県・市区町村は近くの OSM 候補から判定します（15km以内に候補がないものは加えません）。
- 廃寺・合祀などは除外します。
- 知名度の加点：Wikipedia の言語版の数×4（最大60）、一宮30・官幣社25・国幣社15・式内社15・勅願寺15・総本山／大本山15、文化財（世界遺産・国宝40、重要文化財25、特別史跡・特別名勝20、史跡・名勝10、登録有形5 のうち最も高いもの）。

## 除外するもの

- 名前のないもの、日本語の名前がないもの
- 立入禁止（access=private / no）
- 建物の一部や施設名（社務所・手水舎・参集殿・駐車場・霊園・教会 など）
- 戦争遺跡の壕など、パワースポットとして案内するのがふさわしくないもの
- 同じものの重複（同じ Wikidata、または同じ名前で1km以内）。境内の外周線と面の両方がある場合は面だけを使います

## 選び方

知名度の目安で優先度を付けます。

| 条件 | 加点 |
|---|---|
| Wikidata がある | 50 |
| Wikipedia の記事がある | 35 |
| 「神宮」「大社」「総本宮」などの名称 | 70 |
| 八幡宮・天満宮・東照宮・稲荷など | 12 |
| 総本山・大本山・観音・不動尊・大師など（寺院） | 15 |
| 文化財の指定（heritage） | 25 |
| 天然記念物（巨木など） | 30 |
| 公式サイトがある | 8 |
| 境内の広さ | 最大30 |
| 山の標高 | 最大20 |

中心データ1万件は、種類ごとに枠を決めて優先度の高い順に入れます（神社4,000・寺院3,000・滝650・山650・巨木230・湧水220・展望地200・温泉120・岩100・洞窟100・湖80）。残りは神社・寺院・滝などから優先度順に埋め、各都道府県に最低30件は入るよう調整します。

追加データ4万件は、合計での枠（神社21,500・寺院17,000・山3,500・巨木2,700・滝1,300・展望地1,200・祠1,000・岩750・湧水700・湖400・温泉220・洞窟200）まで、中心に入らなかったものから優先度順に選びます。地図には、絞り込みをしていないときは中心データだけを表示し、種類や地域で絞り込むとすべて表示します。

## タグ

- **特徴（データから確かなもの）**：種類に応じて付けます（滝→滝・自然・浄化、山→登山・自然、湧水→湖・湧水・浄化 など）。山頂から500m以内に神社がある山には「霊山」を付けます。
- **ご利益（推定）**：Wikidata の祭神・本尊と、神社・寺院の名称から、一般によく言われるご利益を付けます。画面では「祭神・名称からの推定」と表示します。
  祭神・本尊の例：稲荷神・宇迦之御魂→商売繁盛・金運、八幡神・応神天皇→勝負運・厄除け、菅原道真→学業・合格、大国主→恋愛・縁結び、素戔嗚尊→厄除け、天照大神→開運、猿田彦→交通安全・開運、木花咲耶姫・鬼子母神→安産・子宝、市杵島姫・弁財天→芸事上達・金運、薬師如来・少彦名→健康祈願、不動明王→厄除け、毘沙門天→勝負運・金運、大黒天→金運・商売繁盛、文殊・虚空蔵→学業・合格。
  名称の例は次の表のとおりです。

| 名称に含まれる語 | 付けるご利益 |
|---|---|
| 稲荷 | 商売繁盛・金運 |
| 天満・天神・菅原 | 学業・合格 |
| 八幡 | 勝負運・厄除け |
| 金刀比羅・琴平・金毘羅 | 交通安全・商売繁盛 |
| 恵比寿・戎・蛭子 | 商売繁盛 |
| 出雲・縁結び | 恋愛・縁結び |
| 子安・安産・子授 | 安産・子宝 |
| 厄除・厄神・不動 | 厄除け |
| 弁天・弁財天・厳島 | 芸事上達・金運 |
| 薬師 | 健康祈願 |

- **数秘ナンバー（暫定）**：タグから決めています（例：神社→9・1、寺院→7・4、商売繁盛→8、縁結び→2・6）。占術上の根拠が確立したものではないため、暫定ルールとしています。
