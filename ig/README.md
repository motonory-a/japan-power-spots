## 画像の作り方
1. Canvaの `create-design`(Instagram Post Portrait)。紫と金、セリフ体、写真大きめ。生成回数の上限(quota_exceeded)が出たら2へ。
2. Canvaの書き出しURLはこの環境から直接ダウンロードできない。`ig/fetch.txt` に `名前 | url:<URL>` を追記してpush → GitHub Actions「Fetch Instagram images」が `ig/src/` に保存する。ウィキメディア・コモンズの写真は `名前 | commons:<検索語>` で取れる(ライセンスは `ig/src/名前.json`)。
3. 取ってきた写真に `ig/w1/ps_img.py` で文字を入れる(Canvaと同じ雰囲気)。CC BY/BY-SAの写真は、キャプションの末尾に「📷 作者名 / CC BY-SA 4.0 (Wikimedia Commons)」を入れる。
4. 完成画像は `ig/wN/`(Nは週番号)に置いてpush。Metricoolに渡すURLは `https://raw.githubusercontent.com/motonory-a/japan-power-spots/main/ig/wN/ファイル名` を使う(GitHub Pagesは反映に時間がかかり、直後だと「見つからない」エラーになるため)。

## 予約
- Metricool `createScheduledPost`。providers は instagram、instagramData.type=POST。
- isAiGenerated:AIが作った画像(Canva生成・AI画像)は true、実写は false。
- publicationDate の timezone は Asia/Tokyo。

## 確認のしかた(2026-11-13 変更)
- 本人の確認を待たずに、作ったらそのまま予約まで行う(本人が確認を忘れても投稿が止まらないようにするため)。
- 予約したあと、確認用ページ(画像+全文、曜日タブ)を artifact で公開し、SendUserMessage と通知で知らせる。
- 本人から直したい点が届いたら、投稿時刻までに Metricool の予約を差し替える(updateScheduledPost)。週の最初の投稿まで4〜5日あるので、その間に見てもらう。
- 画像・文章・キャッチコピーは毎回、心理学的に人を引き込む設計で作る(自分ごとの問いかけ、答えを知りたくなる余白、始めるハードルを下げる、続きを見たくなる導線)。事実でないことは書かない。

## 旅行者の写真を集める(2026-11-28 アッキー決定:方法1・3・4を組み合わせる)
サイトとInstagramに「本物の旅行者が門前の一品を楽しむ写真」を載せるため、次の3つを同時に進める。どれも子どもがはっきり写る写真は使わない。写真の許可の記録は必ず残す。

**1. 無料の写真(Wikimedia Commons)でつなぐ**
- ig/fetch.txt の `vis-` で始まる行が、参道のにぎわいの写真。使ってよいのは、後ろ姿・遠くの人混みなど、顔で人がわからない写真だけ。顔がわかる人が写っていたら使わない(ぼかしても使わない)。
- 出典(撮った人・ライセンス)は ig/src/*.json のとおりに表示する。

**2. アッキーが神社で直接お願いする(同意書)**
- 同意書のページ:https://motonory-a.github.io/japan-power-spots/share/ (英・韓・繁中・仏・西。検索には出ない)。言語を最初から選ぶときは `?lang=ko` などを付ける。
- 流れ:声をかける → スマホでこのページを見せる → 名前・表記名(任意)・3つのチェック・指でサイン → 「同意します」で許可の記録の画像がアッキーのスマホに保存される(ページからはどこにも送らない)。
- その場で写真をAirDropか本人のInstagram経由でもらう。同意の画像と写真を一緒に、ドライブの「AI共有/旅行者写真」(なければ作る)に入れる。Claudeはそこから選んでサイトに載せる。
- 声かけの一言(英語):「Hi! I run a free travel guide to Japan's shrines. Could I share your photo with other travelers? It takes one minute.」

**3. Instagramで投稿を募る**
- ハッシュタグ:**#OneLocalBiteJapan**(海外向け全アカウントで同じ)。
- 海外向け(en/kr/tw/fr/es)は月2回、募集の投稿を入れる(「参拝のあとの一品」の回の最後の1枚か、キャプションの最後に入れるのでもよい)。
- 呼びかけ文(各言語):

  - ko: 일본 신사·절 앞에서 맛있는 걸 드셨나요? #OneLocalBiteJapan 을 붙여 올려 주세요. 저희 가이드에 소개할 수도 있어요(꼭 먼저 여쭤봅니다).

## 写真は「話題そのもの」が写っているものだけ（2026-11-19 本人の指摘）
- おみくじの回に京都の住宅街の写真が出てしまい、「おみくじとは無関係な写真。もっとよく考えて写真選定して」と指摘された。
- 写真は、その投稿の話題そのもの（おみくじの回ならおみくじ、5円玉の回なら5円玉やさい銭箱、お守りの回ならお守り）が、ひと目でわかるように写っているものだけを使う。
- 「雰囲気が合う」「同じ地域」というだけの写真は使わない。季節の景色を流用しない。
- 予約前に、全投稿の画像を一覧にして、題名と写真が合っているかを1枚ずつ確かめる。合わないものは取り直す。
- 本人撮影の写真（ig/own）も同じ。写っているものと文章を合わせる。

### ストーリーズの二択も「写っているもの＝言葉」に（2026-11-19 本人の指摘「ストーリーと写真は合うようにして」）
- 二択（A/B）の言葉は、上下それぞれの写真に**写っているもの**にする（例：明治神宮の写真なら「明治神宮にお参り」、おでんの写真なら「おでん」）。「金運」「良縁」「朝」「夕方」など、写真に写っていない言葉はつけない。
- 前振り（今夜の投稿の予告）の背景も、その話題がひと目でわかる写真にする（神社名の回は、その神社の建物・鳥居・おみくじなど）。
- 予約前に、ストーリーズも全言語を一覧画像にして、言葉と写真を1枚ずつ見比べる。
