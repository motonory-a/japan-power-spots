# 九星気学の計算仕様と検証結果（v1.3）

出かける日の方位の吉凶を判定するために採用した決まりごとと、実在の暦との照合結果をまとめます。
流派によって考え方が違う部分があるため、どの方式を採ったかを明記しています。変更したい場合は assets/js/kyusei.js を直します。

## 1. 暦の区切り

- 年の区切りは立春、月の区切りは毎月の節入り（立春・啓蟄・清明・立夏・芒種・小暑・立秋・白露・寒露・立冬・大雪・小寒）。
- 節入りの「日」から新しい年・月として扱います（日本時間）。節入りの時刻より前でも、その日は新しい月の盤です。画面では節入り日であることを表示します。
- 節入りの日時は、天文計算ライブラリ（Astronomy Engine）で1899〜2101年分を計算し、data/solar-terms.js に表として持っています。サイトの表示時に外部へは問い合わせません。
- 生年月日が節入り日の場合、生まれた時刻によって本命星・月命星が変わるため、画面に注意書きを出します。

## 2. 年・月・日の九星

- 年の九星：2017年＝一白から、毎年1つずつ減る（2026年＝一白、2025年＝二黒）。
- 月の九星：寅月（立春〜）の星は、一白・四緑・七赤の年は八白、三碧・六白・九紫の年は五黄、二黒・五黄・八白の年は二黒。以後、月ごとに1つずつ減る。
- 日の九星（A方式）：
  - 冬至にいちばん近い甲子の日を一白として陽遁（1つずつ増える）、夏至にいちばん近い甲子の日を九紫として陰遁（1つずつ減る）。
  - 「いちばん近い」は、冬至・夏至の日が甲子から30日以内なら直前の甲子、31日以上なら直後の甲子。
  - 切替日の間隔が240日になるときは閏とし、その30日前の甲午の日に切り替える（冬は七赤から陽遁、夏は三碧から陰遁）。
  - 2000〜2035年では、2008年冬・2020年夏・2031年冬が閏になります。
- 盤は年・月・日とも順行（後天定位どおりに飛ばす）で配置します。

## 3. 本命星・月命星

- 本命星は生まれた年（立春で区切る）の九星、月命星は生まれた月（節入りで区切る）の九星。

## 4. 方位

- 東西南北は各30°、四隅（北東・南東・南西・北西）は各60°。真北基準。
  北 345°〜15°／北東 15°〜75°／東 75°〜105°／南東 105°〜165°／南 165°〜195°／南西 195°〜255°／西 255°〜285°／北西 285°〜345°
- 方位角は、出発地から目的地への大圏コースの向き（地球を球として最短の向き）。config.js で等角航路（メルカトル地図上の直線）にも切り替えられます。
- 区切り線から3°以内のときは「方位の境界付近」と表示します。
- 出発地から1km未満のスポットは方位なしとします。

## 5. 吉凶の判定

盤ごと（年盤・月盤・日盤）に、各方位を次のように判定します。

- 凶：五黄殺、暗剣殺、本命殺、本命的殺、破（年は歳破・月は月破・日は日破。十二支の対面の宮全体）、定位対冲。
- 最大吉方：その方位に入る星が、本命星と月命星の両方に吉（相生・比和）。
- 吉方：本命星に吉。
- 吉凶なし：上のどれにも当たらない。
- 吉の星から五黄土星と本命星そのものは除きます。

総合の判定（画面の記号）

| 記号 | 条件 |
|---|---|
| × 避けたい方位 | 年盤か月盤で凶 |
| △ 注意 | 年盤・月盤は凶ではないが、日盤で凶 |
| ◎ | 年盤・月盤とも吉（両方が最大吉方なら「最大吉方」と表示） |
| ○ | 年盤か月盤のどちらかが吉 |
| ― | 吉凶なし |

推薦の並び順は「指定時間内 → 年盤・月盤で凶でない → 願いに一致 → 点数」。点数は運気25点満点で、年盤35%・月盤40%・日盤25%の割合で配分します（config.js で変更可）。
本命星が中宮に入る年・月は、八方塞がりとして遠出を控える流派もあるため、画面に注意書きを出します。

## 6. 検証結果

| 照合先 | 内容 | 結果 |
|---|---|---|
| 国立天文台 暦要項（2025〜2027年） | 二十四節気58件の日付・時刻 | 日付すべて一致、時刻差は最大1分 |
| 八雲院 九星気学カレンダー（2026/2/4〜2027/2/3） | 日の九星・日の干支・月の九星 365日分 | すべて一致 ※ |
| 2017年九星カレンダー | 2016/12/8 一白（陽遁始め）、2017/1/1 七赤、2017/2/6 七赤 | 一致 |
| 2029年九星カレンダー | 2029/1/1 一白、1/4 四緑、1月の月盤 九紫（1/5〜） | 一致 |
| 陰遁・陽遁始めの解説記事 | 2024/1/1 一白・6/29 九紫、2019/11/23 一白、2020/6/20 三碧（閏）、2031/12/20 七赤（閏） | 一致 |
| 九星早見表 | 年の九星（2017〜2029年、1974年） | 一致 |

※ 取得したデータでは6月1〜5日が「6月」の見出しの下に並んでいましたが、2026年の芒種は6月6日のため、月の九星は五黄（巳月）として照合しています。

このほか、1901〜2099年の毎日について、日の九星が切替日以外で必ず1つずつ動くことを自動テストで確かめています（tests/run-kyusei-tests.js）。

検証の途中で、冬至・夏至が甲子からちょうど29日後になる年（2019年冬）の扱いで、参考にした計算方法の記事と実際の暦が食い違うことがわかりました。実際の暦（2020年夏に閏）に合うよう「30日以内なら直前の甲子」としています。

## 7. 未対応・注意点

- 月命殺・月命的殺、小児殺、土用期間の扱いは入れていません。
- 宿泊を伴う旅行（何泊かする場合）の判定は、出発日の盤だけで見ています。
- 九星気学は文化的・占術的な考え方で、効果を保証するものではありません。画面にもその旨を表示しています。
