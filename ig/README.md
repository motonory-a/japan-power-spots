## パワースポット系(全言語共通テーマ)
- 曜日テーマ:月 神社・お寺/火 食べ物/水 季節の景色/木 旅の豆知識/金 都市の紹介/土 絶景/日 サイトの紹介
- その時期に合った日本の観光地・食べ物を選ぶ。行事(祝日・祭り)があれば触れる。
- 画像の文字は、必ずそのアカウントの言語で書く(2026-11-16 本人の指摘「全言語で同じ英語の画像では意味がない」)。英語の画像を他の言語のアカウントに使い回さない。
- 文章:各言語で自然に。末尾に「サイトへ 👉 プロフィールのリンク」の一文。ハッシュタグは5個まで。
- 中国語版・韓国語版では靖国神社・護国神社を扱わない。
- 同じ写真を複数アカウントで使い回さない（2026-11-17 本人の懸念を受けて追加）。Instagramは2026-04-30から、同一の画像を複数の場所で見つけると元の1つだけをおすすめに出し、他人の写真を手を加えずに載せることが多いアカウントをおすすめ（発見タブ・おすすめ投稿・リール）から外す。テンプレートのデザインが同じことは問題ではない（ブランドの統一）。問題は「同じ写真」と「手を加えていない他人の写真」。
  - 同じテーマの日でも、言語アカウントごとに別の写真を選ぶ（コモンズには同じ名所の写真が多数ある）。どうしても同じ写真なら、切り抜き位置・構図を大きく変える。
  - リールも言語ごとに写真の組み合わせや順番を変える。
  - アッキー本人が撮った写真があれば優先して使う（オリジナルとして最も強い）。本人の写真は `ig/own/` に置き、`own.json` に場所（本人の申告のまま）と使った日・アカウントを記録する。場所の説明は、本人の申告と写真から確かに言えることだけにする。
  - 月に1回、各アカウントの「設定 → アカウントのステータス → おすすめできないコンテンツ」を本人に確認してもらう。
- 肩書きは英語表記「Akki, the Higher-Dimensional Negotiator」で統一(他言語に訳さない)。
- 事実(年号・高さ・見頃・アクセス)は確かなものだけ。不確かな場所名は画像にも書かない。

## 画像の作り方
1. Canvaの `create-design`(Instagram Post Portrait)。紫と金、セリフ体、写真大きめ。生成回数の上限(quota_exceeded)が出たら2へ。
2. Canvaの書き出しURLはこの環境から直接ダウンロードできない。`ig/fetch.txt` に `名前 | url:<URL>` を追記してpush → GitHub Actions「Fetch Instagram images」が `ig/src/` に保存する。ウィキメディア・コモンズの写真は `名前 | commons:<検索語>` で取れる(ライセンスは `ig/src/名前.json`)。
3. 取ってきた写真に `ig/w1/ps_img.py` で文字を入れる(Canvaと同じ雰囲気)。CC BY/BY-SAの写真は、キャプションの末尾に「📷 作者名 / CC BY-SA 4.0 (Wikimedia Commons)」を入れる。
4. 完成画像は `ig/wN/`(Nは週番号)に置いてpush。Metricoolに渡すURLは `https://raw.githubusercontent.com/motonory-a/japan-power-spots/main/ig/wN/ファイル名` を使う(GitHub Pagesは反映に時間がかかり、直後だと「見つからない」エラーになるため)。

## 予約
- Metricool `createScheduledPost`。providers は instagram、instagramData.type=POST。
- isAiGenerated:AIが作った画像(Canva生成・AI画像)は true、実写は false。
- publicationDate の timezone は Asia/Tokyo。

## 確認のしかた(2026-11-13 変更)
- 本人の確認を待たずに、作ったらそのまま予約まで行う(本人が確認を忘れても投稿が止まらないようにするため)。
- 予約したあと、確認用ページ(画像+全文、曜日タブ)を artifact で公開し、SendUserMessage と通知で知らせる。
- 本人から直したい点が届いたら、投稿時刻までに Metricool の予約を差し替える(updateScheduledPost)。週の最初の投稿まで4〜5日あるので、その間に見てもらう。
- 画像・文章・キャッチコピーは毎回、心理学的に人を引き込む設計で作る(自分ごとの問いかけ、答えを知りたくなる余白、始めるハードルを下げる、続きを見たくなる導線)。事実でないことは書かない。
