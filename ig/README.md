## パワースポット系(全言語共通テーマ)
- 曜日テーマ:月 神社・お寺/火 食べ物/水 季節の景色/木 旅の豆知識/金 都市の紹介/土 絶景/日 サイトの紹介
- その時期に合った日本の観光地・食べ物を選ぶ。行事(祝日・祭り)があれば触れる。
- 画像は全言語で同じ1枚(英語+漢字の表記)。1080x1440(3:4)。
- 文章:各言語で自然に。末尾に「サイトへ 👉 プロフィールのリンク」の一文。ハッシュタグは5個まで。
- 中国語版・韓国語版では靖国神社・護国神社を扱わない。
- 肩書きは英語表記「Akki, the Higher-Dimensional Negotiator」で統一(他言語に訳さない)。
- 事実(年号・高さ・見頃・アクセス)は確かなものだけ。不確かな場所名は画像にも書かない。

## 天然石(@nigihayahi03)
- 週7本のうち2本は連載「天然石の豆知識 No.○」(番号は `ig/state.json` の nigihayahi_tips_next_no から)。残り5本は石の紹介。
- 写真は本人の実物写真(`ig/stones/`、石の名前は `stones.json`)。stones が null の写真は名前未確認なので、名前を書かない文にするか、本人に確認してから使う。写真が足りなければ本人に頼む(過去分の再利用は可、同じ週に重複させない)。
- 画像は `ig/w1/stone_img.py`(写真+下部に見出し)で作る。見出しは「天然石の豆知識」+石名+一言。
- 文章は本人が書いたような、やわらかい日本語。AIっぽい言い回しを避ける。健康・病気への効果は断定しない(薬機法)。「〜と言われています」程度。
- 末尾の定型(必ず入れる):
```
━━━━━━━━━━
🔮 魂の系統鑑定(無料)
生年月日を入れるだけで、全94種の「魂の系統」と今年の運勢がわかります。
あなたにピッタリの天然石ブレスレットもご提案します。
プロフィールのリンクからどうぞ。
━━━━━━━━━━
```
- ハッシュタグ5個:#天然石 #パワーストーン #天然石ブレスレット #魂の系統鑑定 +その日の1つ。

## 画像の作り方
1. Canvaの `create-design`(Instagram Post Portrait)。紫と金、セリフ体、写真大きめ。生成回数の上限(quota_exceeded)が出たら2へ。
2. Canvaの書き出しURLはこの環境から直接ダウンロードできない。`ig/fetch.txt` に `名前 | url:<URL>` を追記してpush → GitHub Actions「Fetch Instagram images」が `ig/src/` に保存する。ウィキメディア・コモンズの写真は `名前 | commons:<検索語>` で取れる(ライセンスは `ig/src/名前.json`)。
3. 取ってきた写真に `ig/w1/ps_img.py` で文字を入れる(Canvaと同じ雰囲気)。CC BY/BY-SAの写真は、キャプションの末尾に「📷 作者名 / CC BY-SA 4.0 (Wikimedia Commons)」を入れる。
4. 完成画像は `ig/wN/`(Nは週番号)に置いてpush。公開URLは `https://motonory-a.github.io/japan-power-spots/ig/wN/ファイル名`。

## 予約
- Metricool `createScheduledPost`。providers は instagram、instagramData.type=POST。
- isAiGenerated:AIが作った画像(Canva生成・AI画像)は true、実写は false。
- publicationDate の timezone は Asia/Tokyo。

## 確認のしかた(最初の2〜3週間)
- 予約の前に、確認用ページ(画像+全文、曜日タブ)を artifact で公開し、本人に見てもらう。予約は本人のOK後。
- 本人がいない定期実行では:翌週分を作って確認用ページを公開し、SendUserMessage で知らせて、予約はせずに止める(本人のOKを待つ)。
- 確認期間が終わったら(本人が「全部任せる」と言ったら)、確認なしで予約まで行う。
